# ♔ Chess Battle & War Strategy

> *"The board remembers what the mind forgets — every sacrifice carries the weight of war, and only those who master patience will conquer."*  
> — **Perez**

An immersive chess game that transforms every match into a military battle — powered by Magnus Carlsen's playing style.

## 🎮 Features

- **Full Chess Engine** — Complete chess rules with python-chess
- **Magnus-Style AI** — AI tuned to play like the world's best chess player
- **Battle Narratives** — Every move described as a military action
- **Progressive Learning** — Tutorial system from beginner to advanced
- **5 Difficulty Levels** — Recruit → Soldier → Captain → General → Magnus Mode
- **War-Themed UI** — Parchment boards, military aesthetics, battle HUD

## 🚀 Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run the game
python main.py
```

## 🎯 How to Play

1. Launch the game and select **New Battle** from the main menu
2. Choose your difficulty level (start at Recruit, work your way up)
3. Click a piece to see valid moves, then click the destination square
4. Watch the battle narrative unfold with each move
5. Learn from the AI's Magnus-style strategic decisions

## 🧠 AI Difficulty Levels

| Level | Name | Style |
|-------|------|-------|
| ⚔️ 1 | Recruit | Learning basics, makes mistakes |
| ⚔️ 2 | Soldier | Solid fundamentals, some tactical awareness |
| ⚔️ 3 | Captain | Strong tactics, good positional sense |
| ⚔️ 4 | General | Advanced strategy, few mistakes |
| ⚔️ 5 | Magnus Mode | Full Magnus Carlsen style — positional mastery |

## 📖 Learning Path

The tutorial system teaches chess through a military lens:
1. **Basic Training** — Piece movement and rules
2. **Tactical Drills** — Forks, pins, skewers, discoveries
3. **Strategic Command** — Pawn structure, piece activity, planning
4. **Opening Operations** — Magnus's favorite openings explained
5. **Endgame Mastery** — Converting advantages like Magnus

## 🛠️ Tech Stack

- **Python 3.10+** with **Pygame 2.5+**
- **python-chess** for move generation and validation
- Custom AI engine with Magnus-tuned evaluation
